Campos nativos do Ploomes que possuem algum tipo de comportamento especial:

O Ploomes possui outros campos nativos que podem ser conferidos diretamente usando a API do software. Entretanto, os campos abaixo possuem algum tipo de comportamento especial. Com eles, evitamos a necessidade de criar campos dinâmicos com automações complexas por trás.

Campos nativos de clientes com comportamentos especiais:
- Nome: campo nativo usado para identificar o cliente. Pode ser preenchido durante a criação e durante a edição, mas não é obrigatório para criação. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- Imagem: armazena a URL de uma imagem do cliente. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- Empresa: campo que permite vincular, formalmente, uma pessoa a uma empresa, ou uma empresa a uma outra empresa. Permite a seleção de apenas uma opção. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- Telefone: um tipo de campo que permite a inclusão de vários telefones. Para cada telefone, eu posso selecionar uma máscara (telefone no formato brasileiro, por exemplo) e um tipo de telefone (comercial, celular, residencial, fax, outros). Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- CEP: precisa possuir uma máscara que formata e valida o CEP de acordo com o padrão brasileiro. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- Cidades, estados e país: o campo de Cidade puxa da lista central de cidades do Ploomes. Os campos de estado e país não são preenchíveis manualmente, já que uma cidade obrigatoriamente tem um estado e um país vinculados a ela, e estes se tornam portanto o estado e o país do cliente. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- CNPJ e integração com receita federal: o Ploomes possui uma integração com receita federal que, ao preencher o CNPJ, busca dados como endereço, sócios, etc. Entretanto, isso fica no frontend padrão do Ploomes. No software que você vai desenvolver para atender à demanda, é importante trazer essa possibilidade de consulta à API do Ploomes com a receita federal. Propriedades do campo CNPJ: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- Marcadores: o Ploomes puxa os marcadores dos clientes de uma base de marcadores de clientes. Esses marcadores tem cor e nome. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- Criador: preenchido automaticamente com o usuário que criou o cliente. Não pode ser editado. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Data de criação: preenchido automaticamente com a data em que foi criado. Não pode ser editado. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Empresas: campo que permite vincular uma pessoa ou uma empresa a múltiplas empresas. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Sim; obrigatório para criação: Não.
- ID da importação de atualização (novo): armazena o ID da última importação que atualizou dados do cliente (se houver). Não pode ser alterado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- ID da importação de criação (novo): armazena o ID da importação que criou o cliente (se houver). Não pode ser alterado. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- ID do formulário externo de atualização: armazena o ID do último formulário externo que atualizou dados do cliente (se houver). Não pode ser alterado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- ID do formulário externo de criação: armazena o ID do formulário externo que criou o cliente (se houver). Não pode ser alterado. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Lead origem: funcionalidade descontinuada, não usar. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Tipo: campo que define se um cliente é uma empresa ou pessoa. Não pode ser alterado. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Não; obrigatório para criação: Não.
- Possui tarefas agendadas: campo calculado em tempo real, ou seja, não pode ser editado. Diz se existe pelo menos uma tarefa em aberto vinculada ao cliente ou não. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Importação de criação: funcionalidade descontinuada, não usar. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Importação de atualização: funcionalidade descontinuada, não usar. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Última atualização: campo que armazena a data em que o cliente foi atualizado pela última vez. Não pode ser editado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Último atualizador: campo que armazena o ID do último usuário que atualizou o cliente. Não pode ser editado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Última venda: campo que armazena o ID da última venda gerada no cliente. Não pode ser editado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Último documento: campo que armazena o ID do último documento gerado no cliente. Não pode ser editado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Último contato: campo que armazena o ID do último registro de interação gerado no cliente. Não pode ser editado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Último negócio: campo que armazena o ID do último negócio gerado no cliente. Não pode ser editado manualmente. Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Próximo aniversário: campo calculado em tempo real, ou seja, não pode ser editado. Devolve a data do próximo aniversário, com base na data preenchida no campo "Data de nascimento" (caso esteja preenchido). Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Último aniversário: campo calculado em tempo real, ou seja, não pode ser editado. Devolve a data do último aniversário, com base na data preenchida no campo "Data de nascimento" (caso esteja preenchido). Propriedades: preenchível durante a criação: Não; preenchível durante a edição: Não; obrigatório para criação: Não.
- Produtos: campo nativo que lista todo os "produtos do cliente" vinculados ao cliente. Propriedades: preenchível durante a criação: Sim; preenchível durante a edição: Não; obrigatório para criação: Não.
- Responsável e usuários colaboradores: campos que permitem vínculo de usuários. Responsáveis por reger os níveis de acesso relacionados a clientes. Para o caso de pessoas vinculadas a empresas, o responsável delas é preenchido automaticamente com o responsável da empresa. Ou seja, nessa situação, o campo de responsável só pode ser alterado automaticamente a partir do responsável da empresa, sem alteração manual.
